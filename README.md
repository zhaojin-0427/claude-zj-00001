# 宠物疫苗接种档案与到期提醒平台

技术栈：**Flask（SQLite）+ Vue 3 + TypeScript + Vite + Element Plus + Chart.js**

## 功能

| 模块 | 说明 |
| --- | --- |
| 宠物档案 | 主人信息登记、宠物档案（物种/品种/性别/出生日期/芯片/绝育），详情页查看**完整接种史**时间线与抗体记录、各疫苗当前免疫状态 |
| 接种登记 | 必须选择**与宠物物种匹配、未过期、库存大于零**的批次，自动带出批号与厂家；医生登记注射部位、不良反应（无/轻微/严重+描述）、下次接种建议；系统按疫苗标准间隔**自动计算到期日**（可手动覆盖）。后端在**同一 SQLite 事务**中完成接种记录创建、库存扣减、流水写入（并自动完成随访计划），任一步失败全部回滚 |
| 疫苗库存 | 登记疫苗批次（批号/厂家/生产日期/有效期/入库数量/预警阈值/操作人/备注），同一疫苗+批号唯一；按疫苗、批号及**正常/低库存/临期/已过期**状态检索（状态按剩余数量与有效期实时计算）；支持带原因的**入库补充**与**库存调整**（盘盈/盘耗，禁止负库存），并可查看每批次库存流水 |
| 到期提醒看板 | 每只宠物 × 每种适用疫苗的状态：已逾期 / 30天内即将到期 / 从未接种 / 免疫有效；支持筛选、搜索主人电话、一键跳转登记；可勾选"已逾期/即将到期"记录**批量生成随访计划**（整体事务，任一校验失败全部回滚） |
| 免疫随访计划 | 随访计划列表（待确认/已确认/已完成/已取消），按状态、计划日期、宠物或主人检索；支持确认、改期、取消；登记对应宠物+疫苗的接种记录后自动完成最近一条未结束计划；宠物详情页展示历史计划 |
| 抗体趋势图 | 按宠物查看各疫苗抗体滴度折线趋势（阳性/弱阳性/阴性彩色标点）、结果汇总，支持登记新检测 |
| 数据统计 | 各疫苗接种覆盖率（横向对比图+明细表）、不良反应率（环形图+严重率）、到期未接种比例（逾期+从未接种）、各疫苗抗体阳性率、随访计划总数/七日内待执行数/完成率、近12月接种趋势、近期不良反应清单、**当前库存总量 / 30天内临期数量 / 低库存批次数 / 本月消耗量** |

## 启动

### 1. 后端（端口 5000）

```bash
cd backend
pip install -r requirements.txt
python3 seed.py     # 初始化数据库并写入演示数据（8 位主人 / 14 只宠物 / 95 条接种 / 25 条抗体检测 / 8 条随访计划 / 32 个库存批次）
python3 app.py      # http://localhost:5000
```

> 后端优先使用 Flask；当环境**未安装 Flask**（如离线容器）时，`python3 app.py`
> 会自动切换到零依赖的标准库服务器（`stdlib_server.py`，基于 `http.server`），
> 接口路径、参数与返回结构与 Flask 版本完全一致，可直接被前端代理调用。
> 生产环境仍建议安装 `requirements.txt` 中的 Flask。

### 2. 前端（端口 5173）

```bash
cd frontend
npm install
npm run dev         # http://localhost:5173 （/api 已代理到 5000）
```

打开 http://localhost:5173 ，默认进入"到期提醒"看板。

## API 概览

- `GET/POST /api/owners` 主人
- `GET/POST /api/pets`、`GET /api/pets/:id`（含接种史、抗体记录、各疫苗状态；**历史接种记录无库存批次仍可正常查看**）
- `GET /api/vaccines` 疫苗字典（按物种过滤）
- `GET/POST /api/vaccinations` 接种记录（POST 必须带 `batch_id`，自动计算 `next_due_date`，**事务内扣库存并写消耗流水**）
- `GET/POST /api/antibodies` 抗体检测
- `GET /api/reminders?status=&species=&q=` 到期看板数据
- `GET /api/inventory/batches?vaccine_id=&batch_no=&status=&species=&usable=` 库存批次（状态实时计算）
- `POST /api/inventory/batches` 登记新批次（首次入库）
- `POST /api/inventory/batches/:id/restock` 入库补充（正整数数量 + 原因）
- `POST /api/inventory/batches/:id/adjust` 库存调整（带符号 change + 原因，禁止负库存）
- `GET /api/inventory/transactions?batch_id=&type=` 库存流水
- `GET /api/followup-plans?status=&date_from=&date_to=&q=` 随访计划列表
- `POST /api/followup-plans/batch` 批量生成随访计划（事务，失败全部回滚）
- `POST /api/followup-plans/:id/confirm|reschedule|cancel` 确认 / 改期 / 取消
- `GET /api/stats` 覆盖率 / 不良反应率 / 到期未接种比例 / 抗体阳性率 / 随访计划指标 / 库存指标

## 疫苗库存规则

- 数据结构：`vaccine_batches`（库存批次）+ `inventory_transactions`（库存流水）
- 批次字段：疫苗、批号、生产厂家、生产日期、有效期、首次入库数量、当前剩余、预警阈值、操作人、备注
- 校验：同一疫苗 + 批号唯一（数据库唯一索引）；入库/消耗/调整数量均为正整数；有效期不得早于生产日期（CHECK 约束）；剩余数量永远 ≥ 0（CHECK + 条件更新双重保证）
- 批次状态实时计算，优先级：**已过期 > 临期（30 天内到期）> 低库存（剩余 ≤ 预警阈值）> 正常**；`usable` = 未过期且剩余 > 0
- 流水类型：`inbound` 入库补充 / `consume` 接种消耗 / `adjust` 库存调整，每条记录数量、带符号增减、变动后结余、原因与操作人
- 接种登记在同一事务内：创建接种记录 → 条件扣减批次剩余（`remaining > 0` 才扣）→ 写消耗流水；消耗流水对 `vaccination_id` 有部分唯一索引，**杜绝重复扣减**
- 历史接种记录 `batch_id` 可为空，列表与宠物详情使用 LEFT JOIN/不依赖批次，**不会因缺少库存批次而无法查看**

## 随访计划规则

- 状态流转：`待确认 → 已确认 → 已完成`，未结束（待确认/已确认）的计划可取消；**已完成或已取消的计划不可再修改**
- 同一宠物 + 同一疫苗**最多存在一条未结束计划**（待确认/已确认）
- 计划日期不得早于当天（创建与改期均校验）
- 批量创建使用数据库事务，任一记录校验失败时**全部回滚**
- 登记对应宠物 + 疫苗的新接种记录后，系统自动将最近一条未结束计划标记为**已完成**

## 到期计算规则

- 接种登记日 + 疫苗标准间隔天数（犬猫核心苗 365 天、兔瘟苗 180 天）= 下次到期日
- 状态判定：到期日早于今天 = **已逾期**；30 天内 = **即将到期**；有有效记录 = **免疫有效**；无记录且日龄 ≥ 60 天 = **从未接种**
- 覆盖率分母为"到龄应种组合数"（宠物数 × 适用疫苗数，60 日龄以下不计）
